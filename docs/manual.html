전자칠판 플로팅 툴 (WFT) 사용 설명서

버전 1.0 · 교사용 화면 조작 도구 · 키보드 없이 터치만으로 모든 기능 사용

1. 시작하기

실행 방법WFT.exe를 두 번 탭합니다. 관리자 권한이나 설치 과정이 필요 없습니다. USB에 담아 어느 PC에서든 바로 실행할 수 있습니다.
화면 배치실행하면 화면 오른쪽 가장자리에 세로 막대 모양 플로팅 바가 나타납니다. 어떤 화면 위에도 항상 표시되며, 수업 자료를 가리지 않도록 크기가 작고 반투명입니다.
트레이 아이콘작업표시줄 오른쪽 아래 트레이에 아이콘이 생깁니다. 두 번 클릭하면 바를 숨기거나 다시 보여 줍니다. 마우스 오른쪽 클릭으로 표시/숨김, 설정, 종료 메뉴를 쓸 수 있습니다.

2. 기본 조작

위치 이동바 맨 위의 손잡이(☰ 모양)를 손가락으로 누른 채 원하는 위치로 끕니다. 화면 가장자리에 가까이 대면 착 붙습니다.
접기 / 펼치기손잡이 아래의 접기 버튼(‹)을 탭하면 작은 원 버튼 하나만 남고 사라집니다. 원을 다시 탭하면 펼쳐집니다. 손잡이를 두 번 탭해도 접히고 펼쳐집니다.
투명도 조절손잡이를 약 1초간 길게 누르면 투명도 슬라이더가 나타납니다. 밝게(20%)부터 진하게(100%)까지 조절하면 손을 뗄 때 자동 저장됩니다. 설정 > 모양에서도 조절할 수 있습니다.
터치하면 선명하게기본 켜짐. 손가락이 닿는 순간 바가 선명해지고 손을 떼면 다시 옅어집니다. 투명도 슬라이더와 설정 > 모양에서 끌 수 있습니다.
종료바 맨 아래 종료 버튼을 탭하거나 트레이 아이콘 오른쪽 클릭 > 종료를 선택합니다.

3. 창 관리 기능

창 전환탭하면 지금 열려 있는 창 목록(미리 보기 그림 + 제목)이 뜹니다. 전환할 창을 탭하면 그 창이 바로 앞으로 옵니다. 최소화된 창도 선택하면 복원됩니다.
이전 창 / 다음 창목록 없이 한 번의 탭으로 바로 직전 창(또는 다음 창)으로 전환합니다. 교수자료와 자료실 화면을 번갈아 보여 줄 때 편합니다.
작업 보기Windows 작업 보기 화면을 엽니다. 열려 있는 창과 가상 화면을 한눈에 볼 수 있습니다.
좌 / 우 / 상 / 하 스냅현재 선택된 창을 화면 왼쪽·오른쪽 절반에 붙이거나, 상(최대화)·하(이전 크기로)로 만듭니다.

스냅 레이아웃 (여러 창 한 번에 배치)

  • "레이아웃" 버튼을 탭합니다.
  • 원하는 배치 모양(2분할, 1+2, 3분할, 4분할, 전체)을 탭해 선택합니다. 파란색으로 칠해진 칸이 실제 화면 분할 모양입니다.
  • 커진 배치도에서 번호가 붙은 영역을 탭합니다.
  • 그 영역에 넣을 창을 목록에서 탭하면 창이 해당 자리에 배치되고, 다음 빈 영역 선택창이 자동으로 이어집니다.
  • 모두 배치했으면 "완료"를 탭합니다. 중간에 그만두려면 패널 바깥을 탭하면 됩니다.

4. 브라우저 탭 기능 (Chrome / Edge)

탭 목록열려 있는 브라우저의 탭 전체 목록을 보여 줍니다. 탭을 탭하면 그 탭으로 바로 이동합니다. 탭이 많을 때 화면 위 화살표 키(Ctrl+Tab)보다 빠릅니다.
이전 탭 / 다음 탭한 번의 탭으로 왼쪽·오른쪽 탭으로 이동합니다.
탭 버튼이 회색으로 변해 있으면 브라우저 창이 선택되어 있지 않다는 뜻입니다. 먼저 브라우저 창을 열거나 창 전환으로 브라우저를 선택하면 버튼이 활성화됩니다.

5. 화면 전환 (가상 화면)

하나의 모니터로 여러 개의 화면(가상 화면)을 만들어 수업 단계별로 전환할 수 있습니다. 예: 1번 화면은 PPT, 2번 화면은 영상 자료.

새 화면전환 만들기새 가상 화면을 만들고 그 화면으로 이동합니다.
이전 / 다음 화면만들어 둔 화면 사이를 앞뒤로 이동합니다.
현재 화면전환 닫기현재 화면을 없앱니다. 열려 있던 창들은 이전 화면으로 자동 이동되므로 안심해도 됩니다.
키보드 사용키보드로는 Ctrl + ⊞Windows + ← / → 키로 화면을 전환할 수 있습니다.

6. 설정

기능바에 표시할 기능을 토글로 켜고 끕니다. ⋮⋮ 표시를 끌어 순서를 바꿀 수 있고, 오른쪽 미리 보기에 실시간으로 반영됩니다.
모양테마(다크/라이트/시스템/고대비), 버튼 크기(44/56/72px), 한글 라벨 표시, 바 방향(세로/가로), 불투명도(20~100%)를 조절합니다.
동작패널 자동 닫힘(끄기/2/3/5초), 표시/숨김 전역 단축키, 스냅 레이아웃 방식(자체 패널/Windows 기본), 시작 프로그램 등록·제거를 설정합니다.
정보사용 설명서(PDF) 보기, 로그 폴더, 설정 폴더, 기본값으로 되돌리기가 있습니다.
시작 프로그램에 추가해 두면 Windows 시작 시 자동으로 실행됩니다. 이미 등록되어 있으면 "이미 시작 프로그램에 추가되어 있습니다"라고 알려 줍니다.

7. 문제 해결

탭 버튼이 회색선택된 창이 브라우저(Chrome/Edge)가 아닙니다. 브라우저 창을 선택한 뒤 사용하세요.
탭 목록이 안 읽힘드물게 브라우저 상태에 따라 목록을 읽지 못할 수 있습니다. 패널에 표시되는 "이전 탭/다음 탭" 버튼을 사용하세요.
일부 창이 전환·스냅 안 됨관리자 권한으로 실행된 프로그램(작업 관리자 등)은 보안상 제어할 수 없습니다.
전역 단축키가 동작 안 함다른 프로그램이 같은 조합을 쓰고 있는 경우입니다. WFT가 자동으로 사용 가능한 조합으로 바꾸고 알림으로 알려 줍니다. 설정 > 동작에서 조합을 바꿀 수 있습니다.
모니터를 바꾼 뒤 바가 안 보임모니터 연결 상태가 바뀌면 위치를 자동 초기화하고 알림을 보여 줍니다. 그래도 안 보이면 트레이 아이콘 두 번 클릭으로 표시하세요.
설정이 이상해짐설정 > 정보 > "기본값으로 되돌리기"를 사용하세요. 설정 파일은 자동 백업됩니다.

8. 개인정보·보안

  • 창 제목, 탭 제목은 화면 표시에만 쓰고 저장하거나 전송하지 않습니다.
  • 네트워크 통신은 없습니다. 모든 기능이 PC 안에서만 동작합니다.
  • 설정·로그 위치: %APPDATA%\WhiteboardFloatingTool\
